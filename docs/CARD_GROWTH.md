# 카드 성장과 전투 보상 규칙

- Rarity: N,R,SR,SSR,UR,XR. XR은 초월 전용, 뽑기/합성으로 획득 불가.
- 속성: earth 대지, water 물, fire 불, grass 풀, dark 암흑. 상성 순환 water>fire>grass>earth>dark>water, 유리 1.25배/불리 0.8배/나머지 1배.
- 포지션 healer/tank/dealer/support를 기존 능력 ops(회복/보호/상태이상/공격)에 따라 결정, 화면에 한글 표시. 힐러/탱커 보정은 HP/DEF +10% 또는 회복+10%, 딜러 ATK+5%, 지원 SPD+2 정도의 제한된 보정.
- 대상마다 마지막으로 맞은 속성과 라운드를 기록. 2라운드 이내 서로 다른 공격자 속성 연계 fire→water 증발, water→grass 개화, grass→fire 연소, earth→dark 침식, dark→earth 붕괴: 후속 피해 1.30배. 발동 시 표식 소모(같은 다단히트 재발동 금지), 다음 공격부터 다시 표식 가능. 중독은 표식/연계 제외. 로그에 연계명/추가 피해 표시. 반드시 결정적 시뮬레이션, ruleset 5로 증가.
- 특성 ID: damage, synergy, resist_earth,resist_water,resist_fire,resist_grass,resist_dark. 카드별 서로 다른 최대 2개, 각 0~20. 선택 즉시 첫 +1 비용 차감(빈 선택은 저장하지 않음), 해제/초기화는 이번 범위 아님. 효과 = level*0.01+floor(level/5)*0.05 (20강 40%); 초월 특성은 효과*1.75. 방어 감소율은 최대 70%, damage 본인 속성 공격 증가, synergy는 연계 배율의 추가 증가(1.30+특성효과).
- 특성 강화 비용: 등급 기본 N1 R2 SR3 SSR5 UR8 XR12 × (현재레벨+1 + floor(현재레벨/5)*5). 5강마다 효과 급등, 다음 레벨 비용/효과 UI 표시.
- 분해 1장당 증거 N1 R3 SR6 SSR10 UR25 XR40. 파편 N1%,R3%,SR8%,SSR20%,UR/XR확정1. 서버 비공개 crypto RNG. 본체까지 분해 가능하되 덱에 쓰는 마지막 1장은 보호. 일괄은 정확한 등급과 강화 <=선택 0..15, 기본 중복만(본체 보존), 명시적으로 본체 포함 선택 가능. 강화/특성 카드 소비는 명시적 확인과 정확한 대상/수량 미리보기. 레이스 시 전체 롤백.
- 파편 5개→쌍둥이 임신의 증거1개.
- 초월: 모든 등급 한 단계씩 N→R→SR→SSR→UR→XR, +5 이상 및 선택한 비초월 특성 +10 이상, 쌍둥이 증거1 소모. 해당 특성 초월 처리 및 강화/다른특성 그대로 보존. 이미 초월된 특성 재선택 불가. XR 추가 초월 불가. 한 번에 1장만 초월하며 원본 스택 나머지는 그대로 유지. 같은 등급/강화보다 강함. 반짝이는 초월 표시, reduced-motion 존중.
- 3장 같은 등급→다음등급(UR/XR 불가), SR재료는 각 +1이상, SSR재료 각 +2이상. 2장 같은 등급→같은등급의 다른 기본종류 카드(소재 기본종류 모두 제외; 후보 없으면 소비없이 거절). 중복 장수 가능. XR합성은 불가. 생성 카드는 +0/특성없음/초월없음, 기존 보유한 강화카드 상태에 병합하지 않음.
- 기존 inventory는 카드 ID별 스택/공유 강화 유지. 합성/초월 출력은 별도 UUID 보유ID로 저장(base_card_id 원본 카탈로그ID, rarity_override 유효등급, traits JSON). 기존 행은 base_card_id NULL, rarity_override NULL, traits '[]'. 덱과 API는 보유ID 참조, 동일 baseCardId 중복출전 금지. 복제 강화 재료는 같은 원본 카드의 모든 보유행에서 각 본체 1장을 제외한 중복 수량을 합산한다. 합성·초월 결과도 이 중복 재료로 후속 강화할 수 있으며, 각 보유행의 본체는 남긴다. 일반 뽑기는 기존 카탈로그 스택에 증가. 합성 출력 별도 보유행이므로 강화 상태를 물려받지 않음. 도감 완성률은 고유 baseCardId 기준 100% 이하.
- 높은 등급 기본 성능 SR+3%, SSR+6%, UR+10%, XR=UR*1.35. 승급 시 동일 카드의 원래 스탯 모양으로 등급 파워비 적용(카탈로그가 없는 XR을 평균1로 계산하지 말 것).
- 보통 뽑기 확률 N60%,R28%,SR10%,SSR1.9%,UR0.1%. 하급 N78%,R20%,SR1.9%,SSR0.1%,UR0. SR+/SSR+권은 해당 이상 등급들의 기본 가중치 정규화. 모든 천장 로직/UI/설명 제거(기존 DB열/과거 migration은 남겨도 기능에 쓰지 않음).
- 하급은 별도 low_tickets. normal 무료 일일1장과 기존 credits 유지.
- 일반 rookie/regular/veteran 승리 보상 하급 2/3/4장, 일반 ace/boss 보통2/3장. 하드 rookie/regular/veteran/ace 보통3/4/5/6장, 하드boss SR+2장. 카오스 rookie/regular/veteran SR+2/3/4장, chaos ace/boss SSR+2/3장. 매 승리 확정 지급, 최초승리는 같은 종류/수량 추가 한번. daily는 기존 일일 첫승 보상만 유지. 별도 기존 랜덤 티켓 드롭 제거하여 tier 계약 지킴. 재정산/동시 finish 중복지급 불가, 실제 지급 receipt 표시.
- 상대 스케일 기존 대비 일반 ace HP/ATK/DEF 1.18, boss1.2; 하드 rookie~ace1.15, 하드boss0.92; chaos 기존유지. 카드 자체 상향과 역할 특성 보정은 공통 적용.
- 전투 정산 성공 후 결과 dialog에 보상과 나가기 버튼. 네트워크 실패는 재시도 제공, 재생에는 정산 호출 없음.
- 덱 목록/선택 카드 +n 표시, 등급 내림/오름 정렬. 유효등급/초월/포지션/속성 표시.

- 공개 쿠폰 `LIMKETMON`: SSR 이상 뽑기권 1장, 보통 뽑기권 10장, 하급 뽑기권 50장. 계정당 1회. 기존 보장권 쿠폰은 유지.
